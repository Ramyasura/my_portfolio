MediEthiCare

Healthcare Management System for Medical Emergencies

Project Overview

MediEthiCare is a healthcare management application developed to help users access healthcare services during medical emergencies. It connects patients, hospitals and administrators through a centralized platform.

Problem Statement

During medical emergencies, finding available hospitals, medical services and required medicines can be difficult. This application aims to simplify access to healthcare information and services.

Project Objectives

  • Provide access to hospital information.
  • Help users find available healthcare services.
  • Simplify appointment and medicine ordering processes.
  • Provide symptom-based medicine information.

Key Features

  • User login and registration.
  • Hospital registration and admin approval.
  • Hospital bed, service and medicine information.
  • Appointment booking and medicine orders.
  • Emergency contact and location information.
  • ML-based medicine recommendation using symptoms.

Machine Learning Implementation

Developed a symptom-based recommendation module using a Gaussian Naive Bayes model. The implementation uses symptom data, Label Encoding and a trained model saved using Joblib.

The module was integrated with the Django application to process user inputs and display the model's recommendations. Recommendations are informational and should not replace medical advice or prescriptions.

Technologies Used

HTML CSS JavaScript Python Django SQL Machine Learning NLP Gaussian Naive Bayes
